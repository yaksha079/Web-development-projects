# A Coffee Story

**Brew & Bean** is a basic coffee shop website created using HTML. The website provides information about the café, its story, coffee menu, prices, contact details, and table reservation options.

The project demonstrates the fundamental concepts of HTML, including headings, paragraphs, images, lists, tables, hyperlinks, forms, input fields, dropdown menus, and semantic HTML elements.

The main aim of this project is to apply the HTML concepts learned in the course and create a simple, organized, and user-friendly café website.
